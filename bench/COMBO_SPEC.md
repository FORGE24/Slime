# 五算子连招压测规范（公平对比）

> 本文件只规定**全局参数、执行顺序、输入输出与公平约束**。  
> 不规定矩阵下标顺序、排序算法变体、哈希冲突策略等具体实现手法——但各语言必须在相同参数下产生**相同随机序列**（见 §3）。

## 1. 全局固定（不可改）

| 符号 | 值 | 说明 |
|------|-----|------|
| `SCALE` | `90` | 基准缩放 |
| `SEED` | `666` | 全局唯一随机种子 |
| 时钟 | 系统最高精度**单调**时钟 | 禁止缓存起止时刻之外的“假计时” |
| 浮点 | IEEE-754 **binary64**（`double` / `f64`） | |
| 阶乘 | 只算 `0..11`，使用 `n % 12` 取下标 | 禁止大数阶乘 |
| 摘要 | **MD5**，对 UTF-8 字节 | 禁止其它摘要 |
| 优化 | 编译：等价 `-O0` / 关向量化；解释：关 JIT、禁 numpy/numba 等加速扩展 | |
| 并行 | **禁止**多线程/并行 | 五段严格串行 |

## 2. 由 SCALE 派生的工作量（所有语言必须使用同一组常数）

以下公式固定，禁止再调参：

```text
MAT_N       = SCALE                          # 90
MAT_ROUNDS  = SCALE * 55                     # 4950
MATH_ITERS  = SCALE * SCALE * SCALE * 280    # 204120000
SORT_LEN    = SCALE * SCALE * 280            # 2268000
HASH_OPS    = SCALE * SCALE * 140            # 1134000
STR_ROUNDS  = SCALE * SCALE * 14             # 113400
```

若某机器单次总耗时 `< 20s`，**不得减小上述常数**；应更换更慢的实现路径或接受该机结果，并在报告中注明 CPU。  
（参考实现已在主流台式 CPU、`-O0` 下校准到 ≥20s。）

## 3. 统一伪随机（保证跨语言输入一致）

禁止使用各语言自带的、未规定算法的 `random()`（例如带系统时间播种的 mt19937）。

所有语言必须实现**完全相同**的 LCG：

```text
state : u64
初始   state = SEED   # 666

每次取数：
  state = state * 6364136223846793005 + 1
  u     = state

均匀 double ∈ [0, 1)：
  f64 = (u >> 11) * (1.0 / 9007199254740992.0)   # 2^-53
```

全程**只维护这一个** `state`，五段任务依次消耗随机流，不得重置种子。

## 4. 五段任务（顺序固定）

1. **矩阵**：生成两个 `MAT_N×MAT_N` 的 `f64` 随机矩阵 `A,B`，再执行 `MAT_ROUNDS` 轮「整矩阵乘累加」（结果写入 `C`，轮与轮之间继续累加）。最后对 `C` 全元素求和一次（防死代码消除；和值不打印）。
2. **数学**：循环 `MATH_ITERS` 次：`acc += sin(x) + cos(x) + fact[i % 12]`，其中 `x` 每次从 LCG 取 `f64`，`fact[0..11]` 为预计算阶乘（普通 `f64`）。
3. **排序**：生成长度 `SORT_LEN` 的 `f64` 数组，**原地**完整排序（任选正确排序算法，但必须比较并重排全部元素）。
4. **哈希容器**：插入 `HASH_OPS` 个键值；键为十进制字符串 `"0"`..；值为 LCG `f64`；删除所有键的十进制表示以 `'1'` 开头的项；遍历剩余项对值求和（和值不打印）。容器须为通用哈希表语义；禁止预知容量的“一次性开大数组冒充”。
5. **字符串 + MD5**：循环 `STR_ROUNDS` 次，将固定格式片段拼到结果串（格式：`"#"` + 十进制轮次 + `";"`）；对最终字符串的 UTF-8 字节做 MD5；摘要不打印。

## 5. 输出

- **仅一行**：总墙钟耗时（秒），`printf`/`print` 等价于保留 **6 位小数**。
- 无其它日志、进度、校验输出。
- **单次**完整跑完；不取均值。

## 6. 公平约束

- 只用语言标准库 / 自写代码；禁止第三方数值、哈希、字符串加速库。
- 禁止手动 `free` 优化套路、禁止预分配可复用大缓冲、禁止跨段缓存复用数据。
- 禁止用特有高性能 API 偷换算法（例如一句话矩阵乘库、一键 sort 若语言规定须手写循环——本规范允许语言自带的通用 `sort` **仅当** Fox/slime 对等提供；参考 C 实现采用手写堆排序以对齐“手动迭代”精神）。

## 7. 能力门槛（跑分前自检）

语言至少需要：`f64` 算术、二维缓冲、`sin`/`cos`、可变字符串、哈希表、MD5（可自写）、单调时钟。

| 实现 | 状态 |
|------|------|
| `combo_ref.c`（`-O0`） | 参考金标准 |
| FoxLang | 当前缺 `*`/`/`/`%`、数组、哈希、MD5、固定种子 RNG → **无法合规跑满** |
| slime2 | 当前缺 `f64`、`sin/cos`、哈希、MD5 → **无法合规跑满** |
